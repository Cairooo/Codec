# 🎧 Codec — MGS1 Inspired Interface

A **web project** built with **HTML, CSS, and JavaScript**, inspired by the **Codec interface from Metal Gear Solid 1 (MGS1)**.

This project focuses on **recreating the look and feel** of the classic in-game communication system, combining **retro aesthetics** with **modern front-end techniques**.

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

---

## 🎯 Project Goals
- Recreate the **Codec visual style** from MGS1  
- Practice **DOM manipulation** and **CSS animations**  
- Explore **UI design inspired by retro interfaces**  
- Experiment with **sound and interaction elements**

---

## 💡 Highlights
- Faithful recreation of the **original Codec interface**  
- Custom animations and color palette inspired by MGS1  
- Fully functional on **desktop devices**  
- **Responsiveness under development** (not yet optimized for mobile)  
- Project made for **practice and creative experimentation**
